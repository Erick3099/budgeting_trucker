
# Professional Budget System
A modular, object-oriented Python budgeting application that performs tax calculations, tracks expenses, evaluates financial health, and generates an official budget receipt.
Designed with clean architecture principles and separation of concerns
## Overview

The **Budget System Tracker** simulates a financial analysis workflow:
1. Accepts monthly income
2. Applies either flat or progressive tax logic
3. Records multiple expenses
4. Calculates remaining balance
5. Evaluates financial health status
6. Generates a timestamped official receipt

This project demonstrates:
- OOP design
- Modular architecture
- Clean separation of logic layers
- Functional callback strategy pattern
